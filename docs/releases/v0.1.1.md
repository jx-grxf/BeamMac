Fixes for starting the game, the Dock and two cases where BeamMac overwrote game settings.

**Starting**
- Clicking Drive right after opening BeamMac, while Steam was still starting in the background, no longer leaves the game unstarted. BeamMac waits for the Steam login, and restarts Steam if it does not take the launch within 30 seconds.
- The BeamNG launcher window no longer appears in that case; the game starts directly with Direct3D 11.
- The status line shows what BeamMac is waiting for, and a failed start shows the actual error.

**Dock and Game Mode**
- Steam no longer appears in the Dock as a blank icon.
- The game shows up as BeamNG.drive in the Dock and in Cmd-Tab, where it used to be "wine". macOS now counts it as a game, so Game Mode can turn on.

**Settings**
- If BeamNG's settings.json cannot be read, the start stops with an error. Before, BeamMac replaced the file and every setting it does not manage was lost.
- Turning off WASD steering keeps your own keyboard bindings. Before, it deleted the whole keyboard.diff.
