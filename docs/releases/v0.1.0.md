First public release. BeamMac installs Wine, DXMT, D3DMetal and Steam for Windows, then starts BeamNG.drive on Apple Silicon Macs.

**Getting started**
- A setup window checks the Mac, lists every download with size and license, and installs everything with one click.
- After the Steam login, BeamMac opens Steam's install dialog for BeamNG.drive and shows the download.

**Driving**
- Steam starts hidden when BeamMac opens, so the game starts in about 25 seconds.
- The BeamMP button starts the official BeamMP launcher before the game for multiplayer servers. BeamMac downloads it from GitHub, checks its SHA-256 and updates it at most once a day.
- The Game Pack (MSync, AVX for Rosetta, no Steam overlay, two queued frames instead of three) is on by default and can be turned off for comparison.

**Graphics**
- DXMT with MetalFX upscaling, or Apple's D3DMetal.
- Profiles set quality, effects, traffic and frame limit together. Balanced holds 40 fps on 120 Hz displays, so frames stay on screen for the same time.
- Metal HUD with one switch.

**Controllers and mods**
- PlayStation and Xbox controllers work as XInput gamepads, with battery, light bar color and a live input test.
- Mod ZIPs can be added by drag and drop.

**Install**
Open the DMG and drag BeamMac into Applications. This build is not notarized: on the first start, open System Settings → Privacy & Security and click Open Anyway. You need BeamNG.drive on Steam, macOS 14 or newer and about 70 GB free.
